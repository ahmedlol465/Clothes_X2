# Docs

`archive/` holds the design notes and audit reports written during development
(AI response contract, stylist intelligence audit, recommendation engine
reports, feedback learning). They describe how the AI parts were designed and
are kept for reference. File paths inside them refer to the layout before
`backend/src` was split into `routes/`, `lib/` and `services/` (for example
`src/scoring.js` is now `backend/src/services/scoring.js`).
