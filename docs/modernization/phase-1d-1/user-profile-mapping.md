### StyleProfile Storage Format (CRITICAL)

Looking at `UsersService.updateStyleProfile()` (lines 129-137), the StyleProfile `dimensions` field stores **lengths/counts, not actual values**:

```typescript
sp.dimensions = {
  favoriteColors: next.favoriteColors?.length ?? 0,  // Stores COUNT, not array!
  preferredStyles: next.preferredStyles?.length ?? 0, // Stores COUNT, not array!
  avoidedColors: next.avoidedColors?.length ?? 0,     // Stores COUNT, not array!
  heightCm: next.heightCm ?? 0,                        // Stores value (number)
  weightKg: next.weightKg ?? 0,                        // Stores value (number)
  fitPreference: Number(next.fitPreference === 'regular' ? 1 : 0), // Stores 0/1, not string!
  sizes: Object.entries(next.sizes).length,            // Stores COUNT of sizes, not sizes!
} as unknown as Record<string, number>;
```

This is a pre-existing data storage bug — `dimensions` stores numbers instead of the actual legacy values. **Phase 1D-1 should NOT fix this bug.** AuthService should store style profile data in a way that's consistent with how UsersService reads it, or use a simpler initial structure.

**Recommended approach for Phase 1D-1:** Store style profile dimensions as a JSON object with the actual legacy values (not counts), since AuthService is the writer and UsersService is a separate reader that may have its own bugs. The API contract (profilePayload) reads from `legacy-style.ts` which normalizes from `LegacyUser.styleProfile`, not directly from StyleProfile dimensions.

Actually, looking more carefully: `UsersService.profile()` calls `profilePayload(toLegacyUser(user, styleProfile))`. The `toLegacyUser()` function builds `LegacyUser.styleProfile` from `styleProfile.dimensions`:

```typescript
const dimensions = (styleProfile?.dimensions ?? {}) as Record<string, unknown>;
return {
  ...
  styleProfile: {
    favoriteColors: Array.isArray(dimensions.favoriteColors) ? dimensions.favoriteColors : [],
    preferredStyles: Array.isArray(dimensions.preferredStyles) ? dimensions.preferredStyles : [],
    avoidedColors: Array.isArray(dimensions.avoidedColors) ? dimensions.avoidedColors : [],
    heightCm: dimensions.heightCm ?? null,
    weightKg: dimensions.weightKg ?? null,
    fitPreference: dimensions.fitPreference ?? 'regular',
    sizes: {
      top: rawSizes.top ?? null,
      bottom: rawSizes.bottom ?? null,
      shoe: rawSizes.shoe ?? null,
    },
  },
  ...
}
```

So `toLegacyUser()` expects `dimensions` to contain arrays for favoriteColors/preferredStyles/avoidedColors, and numbers for heightCm/weightKg. But `UsersService.updateStyleProfile()` stores counts (numbers) instead of arrays. This means `toLegacyUser()` would get `Array.isArray(0) === false` and return empty arrays — another pre-existing bug.

For Phase 1D-1, AuthService should create StyleProfile with `dimensions` containing the actual legacy values (arrays for lists, numbers for measurements), matching what `toLegacyUser()` expects. This is the correct storage format even if UsersService.updateStyleProfile() has a bug.

## Mapping Function (AuthService Internal)

```typescript
function userToLegacyUser(user: User, styleProfile: StyleProfile | null): LegacyUser {
  const dimensions = (styleProfile?.dimensions ?? {}) as Record<string, unknown>;
  return {
    id: user.id,
    name: user.name ?? user.email.split('@')[0],
    email: user.email,
    passwordHash: user.passwordHash ?? null,
    createdAt: user.createdAt?.toISOString() ?? new Date().toISOString(),
    avatarUrl: user.avatarUrl ?? null,
    styleProfile: {
      favoriteColors: Array.isArray(dimensions.favoriteColors) ? dimensions.favoriteColors : [],
      preferredStyles: Array.isArray(dimensions.preferredStyles) ? dimensions.preferredStyles : [],
      avoidedColors: Array.isArray(dimensions.avoidedColors) ? dimensions.avoidedColors : [],
      heightCm: typeof dimensions.heightCm === 'number' ? dimensions.heightCm : null,
      weightKg: typeof dimensions.weightCm === 'number' ? dimensions.weightCm : null,
      fitPreference: typeof dimensions.fitPreference === 'string' ? dimensions.fitPreference : 'regular',
      sizes: {
        top: typeof dimensions.sizes?.top === 'string' ? dimensions.sizes.top : null,
        bottom: typeof dimensions.sizes?.bottom === 'string' ? dimensions.sizes.bottom : null,
        shoe: typeof dimensions.sizes?.shoe === 'string' ? dimensions.sizes.shoe : null,
      },
    },
    tokenVersion: user.tokenVersion ?? 0,
    role: user.role ?? 'user',
  };
}
```
